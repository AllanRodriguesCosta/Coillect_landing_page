# cOillect — Landing Page

Landing page estática do Projeto Integrador cOillect, desenvolvido na FATEC Cotia no curso de Desenvolvimento de Software Multiplataforma.

## Conteúdo

- Página inicial, explicação do projeto, impacto ambiental e FAQ.
- Página de download com acesso ao painel web e à experiência mobile-first instalável.

## Publicação no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, a branch `main` e a pasta `/(root)`. Após a publicação, a landing estará disponível em `https://allanrodriguescosta.github.io/Coillect_landing_page/`.

> O app cOillect é uma PWA: em celulares compatíveis, abra-o no navegador e use “Adicionar à tela inicial”.
